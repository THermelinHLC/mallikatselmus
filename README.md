# mallikatselmus

Märkätilojen mallikatselmus – mobiilisovellus (PWA).

**Sovellus:** https://thermelinhlc.github.io/mallikatselmus/

- Tarkastuslista osioittain (0 edellytykset, A–F), OK / Huom / Puute / Ei koske, huomiot ja valokuvat
- Mallikatselmuksen edellytysten toteaminen ja erillinen edellytysmuistio
- Kiilto-tuotekirjasto, hankepaketin (.json) tuonti
- Tulostettava muistio (Tulosta → Tallenna PDF-muodossa)
- Toimii ilman verkkoyhteyttä; katselmukset ja kuvat tallentuvat vain laitteelle (varmuuskopio etusivulta)

**Asennus puhelimeen:** avaa osoite Chromessa → ⋮ → Asenna sovellus / Lisää aloitusnäytölle.

PDF-lukija: [pdf.js](https://github.com/mozilla/pdf.js) (Apache License 2.0).
